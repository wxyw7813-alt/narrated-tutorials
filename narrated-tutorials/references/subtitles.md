# 单语、双语与音画同步

新生成视频默认开启单语画面字幕；打开视频就能看见，不依赖播放器自动开启字幕轨。用户需要双语时，默认按上下两行/两组显示原文与译文。也保留独立 SRT、VTT 和可选择字幕轨。

## 怎样生成

中文旁白默认配英文译文，英文旁白默认配中文译文；可以显式指定 target_language。用户说“生成中英双语字幕”时，先由代理逐句准备译文，保留软件名、命令和术语的一致写法，再填写分镜。原文和译文一一对应，配音只读 speech（未填时读 text），不会把译文再朗读一次。运行脚本不隐式调用外部翻译 API。

```json
{
  "subtitles": {
    "mode": "bilingual",
    "burn_in": true,
    "source_language": "zh-CN",
    "target_language": "en"
  },
  "scenes": [{
    "title": "先试听",
    "narration": "先试听一小段。再选择喜欢的声音。",
    "captions": [
      {"text":"先试听一小段。","translation":"Listen to a short preview first."},
      {"text":"再选择喜欢的声音。","translation":"Then choose the voice you prefer."}
    ]
  }]
}
```

完整可运行示例在 `assets/bilingual-project.example.json`；替换成自己的实际截图和内容即可。

- `mode: single`：单语；未给 captions 时按自然句自动分段。
- `mode: bilingual`：双语；每段 captions 都需要 translation。
- `mode: off`：不显示或导出字幕；已绑定语句的指针仍会保留所需测时。
- `burn_in: true`：字幕直接显示到视频画面，默认开启。
- `burn_in: false`：只提供可选择字幕轨和文件，播放器需支持或手动加载。

有些代码、数字和路径需要口播改写，可写 `{"speech":"Python 三点一一。","text":"Python 3.11。","translation":"Python 3.11."}`。所有 speech 连起来应与 narration 一致，脚本会检查，避免字幕与讲稿缺句。

## 为什么可以同步

1. 每个字幕单位是一句完整自然语句，避免逐字拼音频破坏语气。
2. 合成后解码为 48 kHz PCM，按采样位置检测这句实际声音起止；保留安全静音边缘，处理后才确定时间码。
3. 译文直接使用原文的同一组时间码，不单独按字数估时。
4. 画面、字幕和指针使用同一条时间轴；指针可以绑定第几句的开始或结束。
5. 中间分镜音轨保持 PCM，拼接时按时间戳补齐切段边界的静音间隙，整条音轨只编码一次 AAC，避免段长取整和逐段编码补齐时间累积。
6. 画面字幕开始时间向前落到所在帧，避免帧率量化把字幕显示拖到声音后面。

换声线、语速、讲稿或字幕分段后，重新测量音频并计算时间，不沿用旧时间码。这是按句同步，不是逐字卡拉 OK；不同播放器和设备仍应抽查最终成片，不能仅凭文件存在宣称任何场景绝对零误差。

## 已有音频或录屏

本次没有增加自动转录/强制对齐大模型。给已有旁白加字幕时，需要已对齐的句子时间码：

```json
{
  "audio": "narration.wav",
  "narration": "先试听一小段。",
  "captions": [{
    "text": "先试听一小段。",
    "translation": "Listen to a short preview first.",
    "start": 0.32,
    "end": 2.46
  }]
}
```

时间以本段音频第 0 秒为起点。缺少时间码、字幕重叠、超出音轨或缺译文时直接提示修正，不自动回退成按整段时长平均分配。使用外部转录或强制对齐工具时应核对实际音轨，不能把翻译的字符数当成时间依据。

## 输出与检查

双语模式输出 `subtitles.source/target/bilingual.srt` 和 `.vtt`，以及默认 `subtitles.srt` / `.vtt`。`caption-timeline.json` 保存最终时间轴。MP4 带原文、译文、双语三条可选字幕轨；画面字幕已开启时默认不再重复显示软字幕。

字幕区与截图内容分开，避免遮住底部按钮。过长的字幕会要求拆成更短的自然语句；不能通过无限缩小字体或按字数切时间来凑。

交付前检查：开头第一句、切段位置、最后一句；双语是否同时出现；指针是否指向讲解对应位置；字幕是否遮挡关键界面。开发测试覆盖带静音音轨的起点、烧入字幕的首帧，以及连续 20 段拼接后没有累积偏差。
