# 清楚、直观、能跟着做的视频

默认用图解解释关系、原理和先后顺序；讲界面操作时优先展示实际截图或录屏。每段尽量只讲一个操作目标；让编号、高亮框和旁白互相对应，给读者留出看清界面的时间。

没有截图时可以做流程图或明确标为“界面示意”的图，不能把画出来的界面当成真实软件截图。有历史截图时标明历史来源与版本差异；已有录屏就保留其中与讲解对应的实际动作。

## 截图上的标注

`image` 指向实际素材。`callouts` 添加圆形编号；不要把编号放在关键按钮文字上，可以放在旁边。`highlights` 用方框圈出重点。坐标基于原图像素，脚本会按截图实际显示比例换算。

```json
{
  "title": "第一步：打开设置",
  "image": "screenshot.png",
  "narration": "先找到设置按钮，再点击它。",
  "kind": "实际截图 · 操作引导示意",
  "footer": "指针是后期引导动画，实际界面以当前版本为准。",
  "callouts": [{"number":1,"x":260,"y":160}],
  "highlights": [{"x":290,"y":140,"width":220,"height":60}],
  "pointer": {
    "space": "image",
    "keyframes": [
      {"at":0.0,"x":100,"y":300},
      {"at":0.5,"x":360,"y":170,"click":true},
      {"at":0.9,"x":360,"y":170}
    ]
  }
}
```

上例的坐标只是配置例子，实际制作必须按真实截图取点。`at` 是本段时长的比例，0.5 表示一半时间；也可用 `time` 指定本段第几秒，每个关键帧二选一。时间严格递增，不能超出该段。

指针平滑移动，终点处可停留；`click:true` 显示短暂点击光圈。它不会操作真实桌面，也不会替用户安装或配置软件。后期动画应在画面说明或制作记录中标明；如果整个视频由截图拼接，不能称为全程实机录屏。

已有录屏也可用 `pointer.space="frame"` 叠加引导指针，坐标基于最终 1920×1080 画面。原录屏已有清楚的指针时通常直接保留，避免出现两个指针。

## 让其他使用者自己调整

项目顶层 `style` 覆盖 `assets/style-default.json`，例如：

```json
{
  "style": {
    "fps": 20,
    "tail_seconds": 1.0,
    "background": "#f4f7fc",
    "accent": "#315de8",
    "text": "#17243a",
    "highlight": "#ffbf36",
    "pointer_enabled": true,
    "pointer_scale": 1.2,
    "click_seconds": 0.6
  }
}
```

帧率支持 10–30；指针大小支持 0.5–2 倍。调慢内容时优先拆分分镜、补足讲解和停留时间。换声线后仍需核对指针是否与旁白中提到的操作同步；按比例排时间并不是自动理解语义。

交付前抽查真实视频帧：指针是否指中目标、按钮文字是否被遮挡、点击光圈是否在正确时间出现。读者看完每段应知道“现在在哪里、要点哪里、点完应看到什么”。

## 指针跟随语句

关键帧可使用 `{"caption":2,"edge":"start","offset":0.3,"x":500,"y":200,"click":true}`，表示本段第二句开始后 0.3 秒到达目标。caption 从 1 开始，edge 可选 start/end。不要再混用 time/at；换声线后会依据新语句时间自动重算。指针移动的起点和停留仍由前后关键帧决定，应抽查是否与讲解语义相符。开启画面字幕后，截图自动缩小留出字幕区，源图坐标仍由脚本同步换算。
