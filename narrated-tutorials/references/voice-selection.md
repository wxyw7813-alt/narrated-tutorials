# 主动试听与选声

## 在对话里先给用户听

每个新视频项目，如果用户没有明确指定声线或要求沿用上次，先主动提供 2–3 段适合讲解语言的真实试听音频，再等待用户选择。可以继续整理内容和素材，但选声前不批量合成整片。已有偏好用于排列候选；不能只报名字、描述音色或给网页链接来代替音频。用户要“全部试听”时展示当前语言的全部，或按其要求展示所有语言。

优先使用 Skill 自带的 11 段 AI 合成试听，全部是通用演示文案，不含本人参考录音。它们约 9–19 秒；播放无需联网或声音模型，制作新旁白仍需对应引擎。

从 Skill 根目录运行：

```sh
python3 scripts/studio.py listen --language zh --output /absolute/path/to/project/auditions
python3 scripts/studio.py listen --language en --gender female --output /absolute/path/to/project/auditions
```

`listen` 仅使用 Python 3.11+ 标准库，首次试听不必先安装 FFmpeg、edge-tts 或模型。它会检查音频及声线设置的散列，拒绝损坏或已过期的试听，不能把不同配置的旧声音当成当前效果。

输出 JSON 的 `samples[].audio` 给出绝对路径。直接在回复中呈现播放器，标明名字、语言、性别和时长：

```text
晓晓 · 中文女声 · 约 9 秒
![晓晓试听](/absolute/path/to/project/auditions/zh-xiaoxiao-broadcast.mp3)
```

把路径换成工具实际返回的路径，不照抄占位符。宿主能显示音频时优先使用内嵌播放器；宿主不支持时再给出导出的 `index.html` 和文件链接。不要声称启动了原生系统弹窗，也不要自动播放全部音频。

结尾告诉用户“回复声线名字或编号即可”。选择可以由普通聊天回复完成，也可以使用宿主实际提供的单选问题工具。不能把播放器的播放事件当成用户已经选定。

## 试听页怎样选择

`index.html` 支持语言/性别筛选，一次只播放一条。点击“选这个声音”会显示可发给 Codex 的选择语句，也能下载 `voice-selection.json`。网页不会直接向对话发送消息；请用户复制语句回复，或附上下载的配置。

导出目录还包含 `samples.json`、可内嵌的 `auditions.md` 和 MP3。它们是项目产物，不把绝对路径或导出缓存重新提交到共享仓库。

## 选择后再制作

将实际选定的 ID 写入项目：

```json
{"voice":{"preset":"zh-xiaoxiao-broadcast"}}
```

用户明确指定声线、说“沿用上次”或已在当前项目选过，直接尊重选择，不重复要求试听。根据声线准备所需引擎；固定样音能播放，不代表模型已安装。生成新的文字或修改语速、音高、设计描述后，可按需用 `audition` 或短场景制作当前项目的试听；在线生成仍需既有授权，不能因为有预览就推断用户同意发送正文。

Qwen VoiceDesign 跨文本可能变化，固定样音不是同一声纹保证。使用本人声音的试听需要本人或已获授权录音及真实运行的克隆后端，不能用这批通用样音冒充。
